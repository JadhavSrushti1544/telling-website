Telling landing page

1. Extract this ZIP to a folder.
2. Open index.html in a browser to preview locally.
3. Keep the assets folder beside index.html so the cropped app screenshots load.
4. The theme selector offers Default, Day, and Night. The page opens in Night by default.
5. The Google Play buttons link to the Telling app listing.

Note: this is an informational landing page; the Mature Content Filter card describes the in-app setting and does not control the app itself.
